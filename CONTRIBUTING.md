# Contributing

Contribute small architectural recipes the agent can combine: stairs, framed openings, roofs, courtyards, facade systems or furniture. Keep source readable and parameters named in architectural terms.

Each recipe should include:

- An original or explicitly reusable example and the valid parameter range.
- Metre units, Z-up coordinates, stable component IDs and meaningful layer names.
- Native geometry plus a preview generated from the same dimensions and transforms.
- Numeric checks for dimensions, volumes, winding and real openings where relevant.
- Before/after evidence for at least one parameter edit, and a viewed image.
- Known limits and source attribution for any third-party material.

Do not add scraped drawings, customer models, private service captures, API keys, transcripts, proprietary GH programs or machine-specific paths. Add only inputs you have permission to distribute. A recipe can cite an architectural concept without redistributing its reference images.

Run the package validator and the geometry/viewer checks before submitting. A screenshot alone does not establish native geometry validity; a file parser alone does not establish visual fidelity. Keep both forms of evidence.
