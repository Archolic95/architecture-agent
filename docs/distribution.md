# Distribution

This repository offers two delivery forms under one Architecture Agent identity. The existing v0.3.0-beta.3 source plugin remains the Codex/local installation. The v0.3.0-beta.4 release adds an optional ChatGPT web-skill ZIP without changing the desktop plugin code or version.

For ChatGPT web, download `architecture-agent-0.3.0-beta.4-chatgpt-skill.zip`. In ChatGPT, open **Skills**, select **Create**, choose **Upload from your computer**, and upload the ZIP. Start a new Work conversation after installation. This path was observed on one ChatGPT Work account; skill availability and workspace policy can vary by account. A personal/workspace upload is separate from marketplace installation and does not establish a universal directory listing.

Model generation requires a writable workspace, Python 3.12 or 3.13, the pinned dependencies or permission to install them into a project-local environment, and downloadable attachments. On the accepted ChatGPT Work smoke, the skill loaded its scripts, imported all six pinned dependencies, returned the unchanged bundled demo and portable HTML, and the downloaded HTML rendered successfully in Chrome. This establishes one bounded host path, not availability for every account or fidelity on a new building.

A cloud execution host's `127.0.0.1` URL is not the user's computer. The web skill instead creates static previews and a self-contained HTML file for download and opening in a desktop browser. The web workflow does not activate MCP, a loopback service, native Rhino or Grasshopper, native-app dispatch, live preview, arbitrary `.3dm` browser import, or a hosted Architecture Agent service.

GitHub publication and the universal Plugins Directory are separate distribution steps. Public directory submissions require verified publisher identity, applicable package/listing checks, policy attestations and review. Listing URLs and the exact five-positive/three-negative test-case requirement apply to remote MCP submissions; they are not universal requirements for skills-only ZIP uploads. This source beta does not claim directory approval. [Submission process](https://developers.openai.com/plugins/deploy/submission), [requirements by submission type](https://developers.openai.com/plugins/deploy/submission-errors).

No hosted server is required. The desktop plugin's local viewer serves only explicitly registered files from loopback; the web skill does not activate it. The portable viewer embeds its files and uses no external requests. Neither distribution adds telemetry. The host application's model execution, input handling and account limits remain governed by that host.
